## Password Policy Reminder

All passwords must meet these requirements:
- Minimum 8 characters
- At least one uppercase letter
- At least one lowercase letter
- At least one number
- At least one special character
- No common passwords
- No repeating characters (3+ times)
- No sequential characters

**Standard Test Password:** `Jamiah@2k24!`

> **Why this password?** `TestPass123!` is rejected by the validator because `123` is three sequential ASCII characters. `Jamiah@2k24!` has no sequential triplets, no repeating characters, and satisfies all rules: uppercase (J), lowercase (amiah, k), digits (2, 4), special chars (@, !).

## Quick Registration Guide

1. Start the backend server: `cd server && dotnet run`
2. Start the frontend: `cd client && npm run dev`
3. Open Swagger UI: `http://localhost:5000/swagger`
4. Use POST `/api/auth/register` endpoint
5. Copy each account JSON and register manually
6. Verify registration success and note the Display ID
7. Test login with each account
8. Promote Account 29 (Dr. Nader Saeed) to Admin role using SuperAdmin

## Cleanup After Testing

To remove all test accounts after testing is complete:
1. Use SuperAdmin account
2. Access user management
3. Delete test accounts by email pattern: `@test.edu` and `@faculty.edu`
4. Or truncate database and re-seed for fresh start
